# 前提条件

使用 Neo Extension DevTools 开发插件工具进行 NEX 扩展开发之前，必须先完成以下事项：

1. NEX 扩展开发工作需要使用网页端的 Chrome 浏览器，请确保已经安装了 Chrome 浏览器。
2. 请确保已经在销售易系统中开通了开发者平台的 License，且具有开发者平台中任意一个功能的功能权限。关于功能权限的详细信息请参考[设置对象权限](https://doc.xiaoshouyi.com/?sso-domain=login.xiaoshouyi.com#/proMan/workplaceDetail?url=%2F%2Ftasks%2FuserAndPermission_setObjectPermissions.html&id=1154&dir=output_1725956591166&time=1726724597279&proId=804&checkStat=undefined)（**文档中心** > **产品手册** > **PaaS 平台** > **用户及权限管理** > **管理用户权限** > **管理对象级和字段级权限** > **设置对象权限**）。
3. 请确保需要进行扩展开发的业务对象已经开通了 Neo 表单，否则扩展代码发布后将不生效。
