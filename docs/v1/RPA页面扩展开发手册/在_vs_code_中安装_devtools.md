# 在 VS Code 中安装 DevTools

::: info
销售易会不定期发布新的DevTools，所以为使用更多扩展功能，需要及时获取并安装最新的版本。
:::

遵循以下步骤，安装 DevTools：

1. 打开 VS Code。

2. 单击左侧菜单中的![](./graphics/销售易CRM_PaaS_平台_NEX页面扩展开发手册_V2108_topic11_image002.png)（下图红框所示）。
   ![](./graphics/销售易CRM_PaaS_平台_NEX页面扩展开发手册_V2108_topic11_image004.png)

3. 在搜索框中输入 **Breeze DevTools**并搜索，然后单击 **Install**进行安装。
   ![](./graphics/销售易CRM_PaaS_平台_NEX页面扩展开发手册_V2108_topic11_image006.png)
